# 《无尽入侵》核心设计哲学与爽点定义

> 版本：v1.0 | 日期：2026-07-25
> 定位：所有设计决策的最高指导原则。任何新功能/系统/内容在评审时，必须对照本文档回答"它让游戏更好玩了吗？"
> 来源：Deep Research 调研（103 Agent/21 信源/34 声明对抗验证）+ 团队实玩讨论 + 代码 Review 复盘

---

## 一、一句话定义

> **在黑暗的破碎遗迹中，用高亮、夸张、易读的技能特效对抗不断涌出的裂界怪潮，每一局都能说出"我这局走的是什么路线"。**

---

## 二、核心爽点（5 条，按重要性排序）

### 1. 构筑成型感 —— "我这套成了"

玩家能清晰感知自己这局走的是什么流派，并且在中后期感受到"成型了"的质变。

- 进化系统（主技能 Lv5 + 催化 Lv3 → 合并高级技能并释放栏位）是我们的**独特差异化**——VS 没有"释放栏位"的决策张力
- 元素反应（燃烧+冰霜=蒸汽爆炸、冰霜+闪电=超导、闪电+火焰=等离子体）是**第二差异化**——技能搭配产生质变，不是数值叠加
- 三选一必须每张卡都有"想要"的理由，不能出现"三个都是炮灰"的局面
- 天赋改变技能**形态**（连射/分裂/留地面/折射），不改变数值——形态变化玩家能感知，数值变化玩家无感

### 2. 操作心流 —— "我只需要走位"

极简输入（移动 + 1 主动技），认知负担全部转移到走位和构筑决策上。

- 攻击全部自动释放，玩家不需要瞄准
- 主动技只有 1 个按键，但必须有**明确的按键收益**（救命/翻盘/清场）
- 支配/紧张交替：割草的快感 → 精英出场的压迫 → 击杀精英的释放 → 回到割草
- 前 3 波必须让新手活下来，但中后期永远有"我觉得再多一个技能就有机会了"的张力

### 3. 感官反馈 —— "每一秒都有回应"

每个动作都有多层冗余反馈（视觉 + 音效 + 震动），让玩家感到自己的操作"有分量"。

- 命中：飘字 + 音效 + 闪白 + 粒子
- 暴击：更大飘字 + 不同音效 + 金色粒子 + hitstop 顿帧
- 进化：全屏震动 + 特殊音效 + 金边框 + toast 提示
- 死亡：慢镜头 + 红屏 + 低音 + 处置报告
- **hitstop 只在"大事件"时触发**（进化击杀/精英击杀），不能每次命中都停帧——那是卡顿不是打击感

### 4. 风险决策 —— "要不要赌一把"

游戏中存在多个"风险 vs 收益"的抉择点，让玩家主动选择冒险。

- 宝藏哥布林：追（离开安全区域）还是不追？
- 血瓶：冲进怪堆捡（可能受伤）还是放弃？
- 精英砸地：贪输出（站在边缘）还是跑远？
- 升级三选一：选当前强的（即时战力）还是选进化催化件（延迟满足）？
- **这些决策不需要文字提示，玩家通过画面就能感知风险和收益**

### 5. 再来一局 —— "下一局我会更强"

死亡不是终点，而是为下一局铺路。每局结束都有明确的"获得感"。

- 经验 → 等级 → 天赋点 → 天赋树（形态变化，不是数值）
- 碎片 → 武器合成 → 带入下一局改变技能行为
- 金币 → 转盘消耗（战利品分配）→ 碎片/天赋点/经验
- 成就 → 解锁新内容/提供目标感
- **经验/金币给得要"刚好差一点"——让玩家觉得"再打一局就能解锁"，而不是"还差好多"或"随便就满了"**

## 三、设计红线（不可违反）

| # | 红线 | 理由 |
|---|------|------|
| 1 | **天赋/武器不加伤害百分比** | 数值膨胀导致"一招鲜吃遍天"，构筑失去意义。只改形态/行为/概率/范围 |
| 2 | **不做被动回血技能** | 回血堆高了 = 挂机游戏。回血只能通过血瓶（风险拾取）和升级回复（少量） |
| 3 | **广告不打断游戏进程** | 玩家刚爽就被打断 = 卸载。广告只在结算转盘可选（额外转一次） |
| 4 | **金币不卖数值** | 只买皮肤/外观/重置天赋/转盘。卖数值 = 付费赢 = 社区死 |
| 5 | **操作永远只有"移动 + 1 键"** | 认知负担降到最低。多一个按键就破坏心流 |
| 6 | **前 3 波不能卡死新手** | 玩家 2 分钟就死 = 再也不打开。但也永远不能太简单 |
| 7 | **成长走积累不走赌博** | 碎片合成是确定性的，转盘是战利品分配不是抽卡 |
| 8 | **单机优先，离线可玩** | 服务器挂了不影响单机体验。数据本地优先 |

### P1（已完成）

- 12 成就

- 转盘（保留，定位为战利品分配）
- 武器合成（保留，每职业精简到 2-3 把）
- 背包（保留，含排行页签）

### P2（已完成）
- 服务端基础架构（零依赖 Node.js + JSON 存储）
- 反作弊校验
- 排行榜

### P3（当前优先）
1. **天赋树重做为层级结构**（融合版 v2.0：通用 4 层 16 节点 + 专精 3 层 9 节点/职业，终极三选一）→ 详见 `docs/talent-tree-v2.md`
2. **经验/金币经济重平衡**：`exp = kills×0.3 + time×0.5`，`gold = kills×0.1 + time×0.05`，满级 ~30 天
3. **3 个元素反应实现**（燃烧+冰霜=蒸汽爆炸、冰霜+闪电=超导、闪电+火焰=等离子体），统一视觉语言
4. **加 2-3 个新技能**（冰锥术、雷暴云、石魔像），补元素空白
5. **掉落物精简**：从 12 种砍到 5 种（经验球/血瓶/磁铁/碎片/护盾）
6. **转盘改名"战利品分配"**：语言从抽奖改为领取奖励，与"成长走积累不走赌博"红线一致

### P4（后续）

- 精英/Boss 更多出场演出
- 微信小程序/抖音分包适配

## 五、三条验证标准

任何功能上线前，回答这三个问题：

1. **玩家能感知到吗？**（形态变化 > 数值变化，视觉反馈 > 文字说明）
2. **它让"再来一局"的驱动力更强了吗？**（里程碑 > 随机奖励，积累 > 赌博）
3. **它让游戏更杂了吗？**（如果是，砍掉或延后）
