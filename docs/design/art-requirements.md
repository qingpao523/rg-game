## 一、概述

本文档列举 MVP 阶段需要的所有美术资源，按优先级和用途分类。

### 当前美术状态

- 旧版纯色 ColorRect / 低保真占位图全部视为废弃，不再作为后续制作参考。
- 当前版本已经接入 `assets/art/characters/`、`assets/art/enemies/`、`assets/art/maps/`、`assets/art/menu/`、`assets/art/ui/` 等新资源目录。
- P0 Demo 的主菜单、战斗地图、角色、怪物、HUD、升级、暂停、结算已经切换到新美术资源。
- 后续仍可补强 P1/P2：完整动画帧、更多状态 VFX、Boss / 多地图 / 职业半身像。

### 总体风格建议

- **题材**：暗黑奇幻 + 东方道士元素混合（类似《元气骑士》+《哈迪斯》风格化方向）
- **视角**：俯视角 2D
- **分辨率**：微信小游戏手机竖屏，Godot 基准画布 720×1280
- **颜色倾向**：暗色背景 + 亮色技能特效 = 高对比度
- **画幅**：小屏可读优先；角色/怪物用高分辨率 Sprite 在 Godot 内缩放，UI 按 720×1280 触控布局制作

## 十二、技能美术需求 · 逐技能详解

技能分 5 种渲染形态，每种需要不同的美术元素。

### 12.1 技能形态与对应美术

| 形态 | 代码 Handler | 需要的美术元素 |
|------|-------------|---------------|
| 投射物 | `_spawn_projectile` | 飞行中的弹幕 Sprite + 击中的爆炸粒子 |
| 区域 | `_cast_area` | 地面放置的半透明范围纹理 |
| 光环 | `_cast_aura` | 跟随玩家的半透明环绕纹理 |
| 召唤 | `_cast_summon` | 召唤物角色 Sprite（骷髅兵/射手） |
| 附伤/增益 | `_cast_buff` | 玩家身上的 buff 光环 / 图标 |

### 12.11 当前代码中技能渲染方式参考

当前弹幕使用 `Projectile.gd`，创建方式：

```gdscript
# SkillRunner._spawn_projectile()
var proj = preload("res://assets/prefabs/projectile.tscn").instantiate()
proj.global_position = from.global_position
proj.direction = _get_target_direction(from.global_position)
proj.speed = cfg.get("projectile_speed", 400.0)
proj.damage = instance.get_damage()
get_tree().current_scene.add_child(proj)
```

弹幕 Sprite 在 `projectile.tscn` 中，当前是 `ColorRect`（纯色方块）：

```
[node name="Sprite" type="ColorRect"]
size = Vector2(12, 12)
color = Color(1.0, 0.85, 0.2, 1)  # 默认黄色
```

**接入贴图的方式**：将 `ColorRect` 替换为 `Sprite2D` 节点，`texture` 引用对应的弹幕 PNG。
