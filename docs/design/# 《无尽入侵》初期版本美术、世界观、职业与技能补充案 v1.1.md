# 《无尽入侵》初期版本美术、世界观、职业与技能补充案 v1.1

## 1. 项目美术核心定位

《无尽入侵》的美术风格建议定为：

**黑金灾厄档案风 + 东方破败遗迹 + 高亮元素特效 + 2D 俯视角小体型角色。**

一句话概括：

> 像一份被打开的异常灾害档案，玩家在黑暗的破碎遗迹中，用高亮、夸张、易读的技能特效对抗不断涌出的裂界怪潮。

本项目不建议走纯写实、纯国风、纯二次元或纯暗黑路线。
微信小游戏屏幕小、同屏单位多、技能密度高，最重要的是：

1. 角色轮廓清楚。
2. 怪物攻击预警清楚。
3. 技能元素颜色清楚。
4. 地图氛围足够强，但不能抢画面。
5. 进化技能必须比普通技能更有“成型爽感”。

---

## 2. 美术风格关键词

### 2.1 主风格关键词

* 黑金
* 灾厄
* 档案
* 破碎遗迹
* 异界裂缝
* 末日预报
* 东方神秘学
* 高对比技能特效
* 俯视角割草清晰度

### 2.2 不建议的方向

| 方向       | 不建议原因                      |
| -------- | -------------------------- |
| 纯写实暗黑    | 小屏幕下角色和怪物会糊成一团，制作成本高       |
| 纯仙侠国风    | 容易和大量修仙小游戏撞风格，缺少末日感        |
| 纯欧美魔幻    | 和“道士、法老、十字军、女巫、武士”混合职业不够贴合 |
| 纯赛博霓虹    | 会冲淡裂界、灾厄、魔契之书的神秘学气质        |
| 过度可爱 Q 版 | 会削弱入侵、灾厄、死亡结算的压迫感          |

### 2.3 推荐最终风格

**暗色底图 + 小比例角色 + 明亮技能 + 档案式 UI。**

角色和怪物可以略微卡通化，但世界观、UI、特效要偏冷峻。
这样能形成一种“角色好上手，世界有危险感”的反差。

## 3. 画面比例与角色规格

### 3.1 角色比例

推荐角色比例：**2.5 到 3 头身。**

原因：

* 微信小游戏屏幕较小，3 头身比写实比例更容易识别。
* 角色职业特征可以靠大轮廓表现。
* 动画成本低。
* 大量怪物同屏时更清楚。
* 可以同时兼容道士、武士、法老、女巫、十字军这种混合职业。

### 3.2 角色尺寸建议

以 750×1334 竖屏为参考：

| 对象    | 屏幕表现尺寸          |
| ----- | --------------- |
| 玩家角色  | 64px - 80px 高   |
| 普通小怪  | 48px - 60px 高   |
| 冲锋怪   | 64px - 72px 高   |
| 精英怪   | 110px - 140px 高 |
| 宝藏哥布林 | 48px - 56px 高   |
| 召唤物   | 42px - 60px 高   |

### 3.3 描边规则

所有战斗单位建议加轻微描边。

| 对象    | 描边建议          |
| ----- | ------------- |
| 玩家    | 2px 亮边或职业色外轮廓 |
| 怪物    | 1px 深色描边      |
| 精英怪   | 2px 暗红或铜绿描边   |
| 召唤物   | 1px 蓝灰描边      |
| 宝藏哥布林 | 2px 金色边缘高光    |

玩家必须永远比怪物更容易被看到。

## 4. 色彩体系

### 4.1 地图底色

地图底色必须压暗，给技能特效留空间。

推荐色彩：

| 用途   | 颜色方向        |
| ---- | ----------- |
| 地面石板 | 冷灰、青黑、低饱和蓝灰 |
| 裂界纹路 | 暗金、黑紫、血红    |
| 龙骨遗迹 | 灰白、旧骨黄      |
| 青铜残骸 | 铜绿、暗青       |
| 灾厄裂缝 | 黑紫、暗红、金色细线  |
| 雾气   | 蓝黑、紫黑       |

地图不能大面积使用高饱和红、蓝、绿，否则会和技能抢视觉。

### 4.2 职业主色

| 职业   | 主色 | 辅色      | 视觉核心       |
| ---- | -- | ------- | ---------- |
| 道士   | 雷蓝 | 符纸黄、朱砂红 | 符箓、雷光、敕令   |
| 武士   | 冷白 | 墨黑、血红   | 刀光、残影、斩痕   |
| 法老   | 沙金 | 冥紫、石灰白  | 棺椁、沙尘、金面具  |
| 寒冰女巫 | 冰蓝 | 银白、深蓝   | 冰雾、霜纹、碎裂   |
| 十字军  | 圣金 | 铁灰、乳白   | 盾光、十字纹、冲击波 |

### 4.3 元素技能颜色

| 元素 | 主色    | 特效形状       |
| -- | ----- | ---------- |
| 火  | 橙红、赤红 | 爆炸、火舌、燃烧地面 |
| 雷  | 蓝紫、电白 | 折线、电弧、闪烁节点 |
| 冰  | 冰蓝、青白 | 六角霜纹、冰刺、碎片 |
| 毒  | 荧绿、黑绿 | 气泡、腐蚀液、毒雾  |
| 圣  | 金白、淡黄 | 光柱、圆环、碑文   |
| 灾厄 | 黑紫、暗金 | 裂纹、黑星、扭曲波纹 |
| 召唤 | 灰白、幽蓝 | 骨影、灵火、残魂线  |

### 4.4 进化技能颜色规则

进化技能要在原元素色基础上增加**金色边缘**或**黑金裂纹**。

例如：

* 陨石术：火红 + 黑烟 + 金色坠落轨迹。
* 雷网审判：雷蓝 + 金色审判节点。
* 冰棘风暴：冰蓝 + 银白碎裂边缘。
* 圣泉方尖碑：圣金 + 白色治疗波纹。
* 灾厄飞星：黑紫 + 暗金尾焰。

这样玩家一眼能看出：“这个不是普通技能，是成型技能。”

## 5. 单地图美术方案：破碎龙庭

### 5.1 地图定位

初期版本只有一张地图，建议地图名确定为：

**破碎龙庭**

地图概念：

> 一座被裂界吞噬的古代王庭遗迹。龙骨、青铜祭坛、断裂宫墙和现代封锁装置被异常力量拼接在一起，形成不断坍缩的入侵战场。

这张地图要同时承载：

* 东方遗迹感。
* 末日裂界感。
* 怪物入侵感。
* 战斗清晰度。
* 长时间游玩不腻的视觉变化。

### 5.2 地图结构

虽然只有一张地图，但可以用“灾级阶段”制造变化。

| 时间       | 阶段名  | 地图变化             |
| -------- | ---- | ---------------- |
| 0-2 分钟   | 裂界初醒 | 地面暗，裂缝微光，怪物少     |
| 2-4 分钟   | 源质外溢 | 地面黑金纹路变亮，雾气增加    |
| 4-6 分钟   | 龙骨回响 | 地面出现龙骨残影，精英预警增强  |
| 6-8 分钟   | 灾厄扩张 | 边缘黑雾加厚，裂缝变红      |
| 8-10 分钟  | 王庭坍缩 | 远景碎片浮动，屏幕边缘有警报红光 |
| 10-12 分钟 | 入侵临界 | 地图整体更暗，技能和怪物预警更亮 |

这不需要做多张地图，只需要叠加：

* 雾效颜色变化。
* 地面裂纹亮度变化。
* 屏幕边缘暗角变化。
* 少量漂浮碎片。
* 灾级提示 UI。

### 5.3 地图元素清单

P0 必做：

* 可平铺石板地面。
* 黑金裂纹地表。
* 破碎宫墙装饰。
* 龙骨残骸装饰。
* 青铜祭坛装饰。
* 黑雾边缘。
* 裂界光效。

P1 可做：

* 远景漂浮宫殿碎片。
* 现代封锁路障。
* 观测局探照灯残骸。
* 倒塌石碑。
* 地面符文阵。
* 被污染的龙首雕像。

P2 后续做：

* 动态坍缩地面。
* 地图局部事件。
* 可破坏装饰物。
* 地形伤害区。

### 5.4 地图可读性规则

地图是背景，不能抢战斗层。

建议：

* 地图整体亮度控制在 30%-45%。
* 玩家和技能亮度控制在 70%-100%。
* 怪物预警颜色必须高于地图装饰。
* 地面裂纹只做细线，不做大面积发光。
* 龙骨和宫墙不要放在玩家移动主区域正中央。
* 所有装饰物默认不做碰撞，避免寻路复杂化。

## 6. 世界观补充

### 6.1 世界基础

世界分为两层：

**常世**：普通人生活的现实世界。
**裂界**：灾厄入侵后，现实被异常力量撕开的重叠空间。

玩家不是传统勇者，而是被观测局投放进裂界的“执契者”。

### 6.2 核心组织：观测局

观测局负责预测、封锁和处理裂界入侵事件。

它无法阻止灾厄，只能提前预报灾厄发生的位置和等级。
每次战斗，本质上都是一次“灾厄处置任务”。

UI 可以使用这种包装：

* 开始游戏 = 执行处置任务。
* 战斗计时 = 入侵持续时间。
* 升级 = 魔契条目重写。
* 进化 = 高危处置方案解锁。
* 死亡 = 执契者信号中断。
* 结算 = 处置报告生成。

### 6.3 玩家身份：执契者

执契者是能承受裂界污染，并使用魔契之书调用异常力量的人。

不同职业不是普通职业转职，而是不同的“契约类型”。

| 职业   | 契约类型   |
| ---- | ------ |
| 道士   | 符箓敕令契约 |
| 武士   | 断刃斩杀契约 |
| 法老   | 冥棺葬仪契约 |
| 寒冰女巫 | 冻结见证契约 |
| 十字军  | 圣盾封锁契约 |

### 6.4 魔契之书

魔契之书是技能三选一和技能进化的世界观解释。

玩家每次升级时，魔契之书会展开三条新条目。
技能升到满级并满足催化条件后，魔契之书会把两个技能融合成高级条目。

文案示例：

> 魔契之书正在重写条目。

> 条目共鸣确认。

> 低阶术式已合并为高危处置方案。

> 进化完成：雷网审判。

## 7. 职业规划

### 7.1 初期版本职业设计原则

初期版本有 5 个职业，但不建议每个职业都做完整专属技能树。

推荐结构：

**职业主动技 + 职业基础属性 + 推荐技能流派 + 通用技能池。**

也就是说：

* 职业负责手感。
* 技能池负责构筑。
* 美术包装负责职业辨识度。
* 进化负责中期爽点。

### 7.2 五职业定位

| 职业   | 操作难度 | 生存方式     | 推荐流派    | 核心爽点             |
| ---- | ---- | -------- | ------- | ---------------- |
| 道士   | 中    | 中距离清场    | 雷、火、召唤  | 雷符弹射、火焰扩散、骷髅军团   |
| 武士   | 高    | 位移、击杀返还  | 火、雷、灾厄  | 一闪穿怪、残血斩杀、连锁收割   |
| 法老   | 中    | 召唤物抗压    | 召唤、灾厄、圣 | 木乃伊调度、亡者复苏、召唤物强化 |
| 寒冰女巫 | 中低   | 减速、冻结    | 冰、灾厄、区域 | 冰域控场、冻结碎裂、风暴成型   |
| 十字军  | 低中   | 护盾、击退、治疗 | 圣、护盾、火  | 举盾推进、吸收反爆、站桩抗潮   |

### 7.3 当前技能表的职业归属调整建议

你现在的技能表里，道士内容太多。建议改成：

#### 通用技能池

* 魔法飞弹
* 爆裂火球
* 灾厄光环
* 炎附
* 感电烙印
* 弹射闪电
* 天雷击
* 雷云
* 麻痹领域
* 燃烧咒
* 火墙
* 焚身爆
* 召唤骷髅
* 骷髅射手
* 亡者复苏
* 骷髅强化
* 尸爆

这些技能不必全部叫“道士技能”。
它们可以是魔契之书提供的通用条目，只是道士更容易刷到雷/火/召唤相关条目。

#### 职业影响技能出现权重

| 职业   | 高权重技能       |
| ---- | ----------- |
| 道士   | 雷、火、符箓、弹射   |
| 武士   | 火、雷、灾厄、近身爆发 |
| 法老   | 召唤、灾厄、尸爆、强化 |
| 寒冰女巫 | 冰、区域、控制、灾厄  |
| 十字军  | 圣、护盾、治疗、反伤  |

这样不用为每个职业制作大量专属技能，也能让职业体验有差异。

## 8. 五职业美术设定

### 8.1 道士：雷符执令者

视觉关键词：

* 符纸
* 雷光
* 令牌
* 朱砂
* 短袍
* 铜铃

角色轮廓：

* 身后漂浮 3-5 张符纸。
* 一手持令牌，一手掐诀。
* 袍子不宜太长，避免俯视角下糊成一团。
* 主色雷蓝，辅色符纸黄和朱砂红。

主动技表现：

“敕令雷符”释放时，符纸向前飞出，展开成符阵，随后落雷弹射。
暴击触发小落雷时，目标头顶闪过一个红色“敕”字印。

### 8.2 武士：断刃清道夫

视觉关键词：

* 长刀
* 残影
* 血红斩痕
* 黑白对比
* 破损羽织
* 现代识别牌

角色轮廓：

* 刀必须明显长于身体。
* 披着半破羽织。
* 身体前倾，强调速度。
* 主色冷白，辅色墨黑和血红。

主动技表现：

“一闪”不是普通冲刺，而是瞬间消失再出现。
路径上留下白色刀光，敌人身上延迟出现红色斩痕。
击杀返还冷却时，刀身闪一下冷光。

### 8.3 法老：冥棺调度者

视觉关键词：

* 金面具
* 小石棺
* 沙尘
* 木乃伊
* 冥紫光
* 葬仪符号

角色轮廓：

* 头冠或面具夸张。
* 身后漂浮一个小型石棺。
* 手持权杖。
* 移动时脚下有沙尘拖尾。
* 主色沙金，辅色冥紫。

主动技表现：

“冥棺敕命”释放时，战场上的召唤物被沙流拉回。
召回路径造成冲击，随后石棺打开，刷新强化木乃伊。
强化木乃伊身上有金色绷带纹路。

### 8.4 寒冰女巫：冻庭见证者

视觉关键词：

* 冰晶
* 长斗篷
* 霜纹
* 冰环
* 碎裂
* 蓝白雾气

角色轮廓：

* 背后或身侧有悬浮冰环。
* 头发和衣摆带冰晶。
* 法杖可以简化，重点是冰环和斗篷。
* 主色冰蓝，辅色银白和深蓝。

主动技表现：

“极寒领域”释放后，玩家脚下展开六角霜纹。
领域内敌人脚底结霜，动作明显变慢。
结束时冰层由外向内碎裂，对被冻结敌人触发碎裂伤害。

### 8.5 十字军：圣盾封锁者

视觉关键词：

* 大盾
* 金白光
* 铁灰盔甲
* 十字裂纹
* 推进
* 冲击波

角色轮廓：

* 盾牌占角色面积至少 40%。
* 头盔和披风可以简化。
* 武器不需要抢眼，盾才是主体。
* 主色圣金，辅色铁灰和乳白。

主动技表现：

“圣盾冲阵”释放时，角色举盾向前推进。
前方出现楔形金色冲击区，被撞到的敌人后仰并被推开。
结束时根据吸收伤害引发十字形真伤爆发。

## 9. 怪物美术规划

### 9.1 普通怪：裂界残民

定位：最基础杂兵。

视觉：

* 半透明灰黑身体。
* 空洞脸。
* 身上有暗金裂纹。
* 动作像被异常力量牵引。
* 死亡时碎成黑色尘埃和源质小晶体。

玩法：

* 大量出现。
* 血量低。
* 用于测试清怪效率。

### 9.2 冲锋兵：断角龙卒

定位：打断玩家节奏。

视觉：

* 头部有断角。
* 身体前倾。
* 背后有龙骨碎片。
* 冲锋前地面出现红色直线预警。
* 冲锋时拖出黑红残影。

玩法：

* 直线冲刺。
* 逼迫玩家移动。
* 提供武士“一闪”和十字军“圣盾冲阵”的发挥空间。

### 9.3 精英怪：司灾铜像

定位：阶段压力核心。

视觉：

* 青铜巨像。
* 胸口有黑金裂缝。
* 体型明显大于普通怪。
* 攻击前地面出现圆形灾纹。
* 死亡时身体碎裂成青铜片。

玩法：

* 血量高。
* 周期范围攻击。
* 掉落大量经验或特殊奖励。

### 9.4 宝藏怪：秘藏哥布林

建议把“宝藏哥布林”正式命名为：

**秘藏哥布林**

视觉：

* 小体型。
* 背巨大包裹。
* 包裹里漏出金币、符纸、源质结晶。
* 跑动时掉落小光点。
* 被攻击时包裹裂开。
* 死亡时奖励喷发。

玩法：

* 不主动攻击。
* 从屏幕边缘出现。
* 朝远离玩家的方向逃跑。
* 击杀后掉落稀有三选一、经验或临时祝福。
* 未击杀则逃出地图。

提示文案：

> 【异常接近】秘藏哥布林正在搬运本局奖励。

## 10. 技能美术统一方案

### 10.1 技能表现分层

每个技能最好拆成三层表现：

1. **释放提示**：让玩家知道技能马上发生。
2. **主体特效**：技能真正造成伤害或效果。
3. **命中反馈**：敌人受击、爆炸、减速、冻结、感电等。

不能只有主体特效，否则手感会弱。

### 10.2 当前技能视觉设计

| 技能   | 视觉表现                       |
| ---- | -------------------------- |
| 魔法飞弹 | 黑紫色小型飞星，自动追踪，尾部有暗金短拖尾      |
| 爆裂火球 | 橙红火球，命中后圆形爆炸，地面短暂留焦痕       |
| 灾厄光环 | 玩家周围黑紫圆环，边缘有暗金裂纹，敌人进入后身体变暗 |
| 炎附   | 玩家武器或弹幕附加红橙火边，命中有小火花       |
| 感电烙印 | 敌人头顶出现蓝紫烙印，受击时跳电弧          |
| 弹射闪电 | 折线电弧在敌人之间跳跃，每次弹射有白色闪点      |
| 天雷击  | 目标脚下先出现小型符阵，随后竖直落雷         |
| 雷云   | 玩家头顶悬浮小雷云，周期向附近敌人放电        |
| 麻痹领域 | 地面蓝紫电网区域，敌人脚下出现短暂定身电锁      |
| 燃烧咒  | 目标身上出现朱砂咒印，随后燃起黑红火焰        |
| 火墙   | 地面横向火带，边缘有黑烟，敌人穿过时着火       |
| 焚身爆  | 灼烧敌人死亡时体内红光膨胀后爆炸           |
| 召唤骷髅 | 地面骨手伸出，幽蓝火焰闪过后骷髅出现         |
| 骷髅射手 | 骨弓拉弦，发射幽蓝骨箭                |
| 亡者复苏 | 敌人死亡位置出现小型骨阵，骷髅从黑雾中站起      |
| 骷髅强化 | 所有骷髅身上出现蓝白骨纹，体型略微变大        |
| 尸爆   | 骷髅死亡时骨片炸开，中心有幽蓝冲击波         |

### 10.3 主动技视觉强度

主动技比普通技能高一级，但低于进化技能。

| 主动技  | 视觉强度           |
| ---- | -------------- |
| 敕令雷符 | 中高，强调符阵和落雷     |
| 一闪   | 高，强调位移和斩痕      |
| 冥棺敕命 | 中高，强调召回轨迹和棺椁展开 |
| 极寒领域 | 高，强调安全区和冻结碎裂   |
| 圣盾冲阵 | 高，强调推进、击退和爆发   |

### 10.4 进化技能视觉强度

进化技能必须给玩家“我成型了”的反馈。

推荐首批进化：

| 主技能  | 催化技能 | 进化技能 | 视觉表现                        |
| ---- | ---- | ---- | --------------------------- |
| 爆裂火球 | 炎附   | 陨石术  | 屏幕上方出现红黑陨石，地面有落点圈，砸下后留下燃烧地面 |
| 弹射闪电 | 感电烙印 | 雷网审判 | 被感电敌人之间生成蓝紫雷网，节点有金色审判印      |
| 魔法飞弹 | 灾厄光环 | 灾厄飞星 | 黑紫飞星数量增加，命中后扩散抗性削弱波纹        |
| 召唤骷髅 | 骷髅强化 | 白骨军势 | 骷髅数量和体型提升，召唤时出现更大的骨阵        |
| 火墙   | 燃烧咒  | 焚城火线 | 火墙变为多段火线，灼烧敌人死亡后连锁爆炸        |
| 亡者复苏 | 尸爆   | 死灵连锁 | 复活失败的尸体也会爆炸，战场出现连环骨爆        |
| 雷云   | 天雷击  | 九霄雷诏 | 雷云周期召唤小落雷，暴击时额外劈向感电目标       |
| 麻痹领域 | 弹射闪电 | 雷牢阵  | 区域内生成电牢，定身敌人时触发范围闪电         |

初期 Demo 不一定全部实现，优先做 4 个：

1. 陨石术。
2. 雷网审判。
3. 灾厄飞星。
4. 白骨军势。

原因：

* 覆盖火、雷、灾厄、召唤。
* 能直接复用你当前已有技能。
* 视觉差异明显。
* 不需要新增冰系数值表也能先跑通 Demo。

## 12. UI 美术风格

### 12.1 UI 核心概念

UI 不是传统奇幻菜单，而是：

**观测局异常处置终端。**

关键词：

* 档案
* 警报
* 预报
* 条目
* 封锁
* 处置
* 回收
* 信号中断

### 12.2 主菜单

主菜单建议表现为“观测局终端界面”。

按钮文案：

| 普通写法 | 推荐写法   |
| ---- | ------ |
| 开始游戏 | 进入裂界   |
| 选择角色 | 执契者档案  |
| 设置   | 终端校准   |
| 最高分  | 历史处置报告 |
| 退出   | 断开连接   |

### 12.3 战斗 HUD

HUD 要简洁，不能遮挡战斗。

建议布局：

* 左上：生命、法力。
* 顶部中央：入侵时间。
* 右上：暂停。
* 下方右侧：主动技按钮。
* 下方：6 个技能槽。
* 屏幕边缘：秘藏哥布林方向提示。
* 中央上方：灾级提示。

HUD 文案示例：

> 灾级上升：裂界活性增强。

> 异常接近：秘藏哥布林出现。

> 高危单位：司灾铜像苏醒。

### 12.4 升级三选一界面

升级三选一包装为“魔契之书展开”。

每张卡包含：

* 技能名。
* 技能标签。
* 当前等级。
* 升级后变化。
* 是否可进化。
* 是否为进化催化件。

示例：

> 弹射闪电 Lv.3 → Lv.4
> 雷 / 投射 / 连锁
> 伤害 24 → 30
> 弹射衰减 -16% → -14%
> 与【感电烙印】存在进化共鸣。

### 12.5 结算界面

结算界面不要做成普通失败页，而是“处置报告”。

内容：

* 幸存时间。
* 击杀数量。
* 最高等级。
* 技能进化数量。
* 击杀秘藏哥布林数量。
* 本局构筑判定。
* 信号中断原因。

文案示例：

> 执契者信号中断。
> 本次处置报告已生成。

## 13. 单地图长期观感解决方案

只有一张地图时，最大问题是玩家容易视觉疲劳。
解决方法不是加新地图，而是让同一张地图发生阶段变化。

### 13.1 灾级阶段变化

| 灾级  | 画面变化      | 玩法变化   |
| --- | --------- | ------ |
| I   | 地图暗，裂缝弱光  | 普通怪为主  |
| II  | 裂纹变亮，雾气增强 | 冲锋怪加入  |
| III | 龙骨残影出现    | 精英怪加入  |
| IV  | 屏幕边缘红光预警  | 怪物密度提升 |
| V   | 黑雾压迫，地面发光 | 高压怪潮   |

### 13.2 低成本实现方式

* 一张地面贴图。
* 一张裂纹覆盖贴图。
* 一层黑雾粒子。
* 一层远景碎片。
* 一层屏幕边缘暗角。
* 按时间调整透明度和颜色。

这样几乎不增加地图内容量，却能让战斗越来越紧张。

## 14. 当前技能表的补强建议

### 14.1 命名问题

当前技能里大量使用 `taoist_` 前缀，但很多技能其实可以作为通用技能。

建议改为：

| 当前 ID                  | 建议 ID            |
| ---------------------- | ---------------- |
| taoist_thunder_bolt    | thunder_bolt     |
| taoist_thunder_cloud   | thunder_cloud    |
| taoist_paralyze_zone   | paralyze_zone    |
| taoist_burn_curse      | burn_curse       |
| taoist_fire_wall       | fire_wall        |
| taoist_ignite_explode  | ignite_explode   |
| taoist_summon_skeleton | summon_skeleton  |
| taoist_summon_archer   | summon_archer    |
| taoist_raise_dead      | raise_dead       |
| taoist_skull_enhance   | skeleton_enhance |
| taoist_corpse_burst    | corpse_burst     |

道士可以提高这些技能的出现概率，但技能本身不必全部绑定道士。

### 14.2 缺少冰、圣、防御技能

你当前已有火、雷、灾厄、召唤，但寒冰女巫和十字军缺少足够技能支撑。
建议初期至少补 6 个技能。

#### 冰霜结界 frost_barrier

Tag：冰 / 护盾 / 控制
效果：获得护盾，护盾存在期间降低附近敌人移速，护盾破裂时冻结周围敌人。

视觉：蓝白冰壳包住玩家，破裂时向外炸出冰片。

#### 分裂冰锥 ice_shard

Tag：冰 / 投射
效果：向最近敌人发射冰锥，命中后分裂成小冰片。

视觉：冰蓝尖刺，命中后碎成三枚小冰片。

#### 寒霜地脉 frost_ground

Tag：冰 / 区域
效果：周期在敌人脚下生成冰面，造成伤害和减速。

视觉：地面出现六角霜纹，随后冰刺上突。

#### 圣光守卫 holy_guardian

Tag：圣 / 召唤 / 治疗
效果：召唤固定守卫，周期治疗玩家或攻击敌人。

视觉：小型金白石碑，周期释放治疗光环。

#### 钢铁皮肤 iron_skin

Tag：护盾 / 防御
效果：周期获得减伤或护盾。

视觉：玩家身上出现铁灰护甲光泽。

#### 复仇战旗 vengeance_banner

Tag：圣 / 召唤 / 增益
效果：插下一面战旗，提高范围内召唤物或玩家攻击速度。

视觉：金白战旗插地，周围出现圆形增益圈。

### 14.3 初期建议技能池

Demo 初期建议控制在 20-24 个技能。

当前已有 17 个。
再补 6 个后，技能池变成 23 个，比较合适。

推荐结构：

| 类型     | 数量 |

| 火系     |  4 |
| 雷系     |  5 |
| 灾厄     |  2 |
| 召唤     |  5 |
| 冰系     |  3 |
| 圣/防御   |  3 |

这样五个职业都有构筑空间。

## 16. 美术验收标准

### 16.1 战斗画面验收

一张战斗截图里，必须能在 1 秒内看清：

1. 玩家在哪。
2. 怪潮从哪里来。
3. 哪些区域危险。
4. 当前主力技能是什么元素。
5. 是否出现精英或秘藏哥布林。
6. 角色当前是否处于护盾、冻结、感电、灼烧等状态。

如果看不清，说明地图或特效太花。

### 16.2 职业辨识验收

只看小人剪影，不看名字，也应该能分辨：

* 道士：符纸。
* 武士：长刀。
* 法老：石棺。
* 女巫：冰环。
* 十字军：大盾。

如果剪影分不出来，说明设计不合格。

### 16.3 技能辨识验收

只看技能颜色和形状，玩家应该能分辨：

* 火是爆炸和燃烧。
* 雷是折线和弹射。
* 冰是霜纹和碎裂。
* 灾厄是黑紫裂纹。
* 召唤是骨阵和灵火。
* 圣是金白光环。

## 17. 最终建议

初期版本最应该做强的是：

1. **破碎龙庭这一张地图的灾级变化。**
2. **五个职业的剪影差异。**
3. **技能元素颜色统一。**
4. **四个进化技能的强反馈。**
5. **秘藏哥布林的风险奖励表现。**

其中美术优先级最高的是：

> 地图暗下去，技能亮起来，角色轮廓立起来，进化炸出来。

这就是《无尽入侵》初期 Demo 最应该抓住的视觉核心。
