# 10. Godot 导入建议

## 10.1 图标

* 导出 PNG。
* 建议 512×512。
* Godot 内缩放到 64×64 或 96×96。
* 保留高清原图，避免 UI 模糊。

## 10.2 VFX

* 先生成透明背景单帧。
* 再拆成 3-5 个关键阶段：

  * 预警
  * 释放
  * 命中
  * 残留
* Godot 中用 AnimatedSprite2D 或 GPUParticles2D 组合实现。

## 10.3 地图

* Tile 用 256×256。
* 裂纹 overlay 单独一层。
* 黑雾边缘单独一层。
* 地图阶段变化通过 modulate 颜色和透明度完成，不必重做多张地图。

## 10.4 角色

* 先做单帧标准姿势。
* 统一视角和比例。
* 后续再补 idle / run / cast / hit / death。
* Godot 中每个职业保持同样碰撞半径，避免美术体型影响数值。
