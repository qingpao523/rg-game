# 技能全数值设计 v1.0

> 设计目标：Lv.1 可打前 3 波，Lv.5 可打 7-10 波
> 敌人：杂兵 HP20(+5/波)、冲锋兵 HP15(+3/波)、精英 HP80(+20/波)
> 玩家 6 技能栏，每次升级三选一

---

## 一、数值公式

```
伤害 Lv.N = base + per_level × (N-1)
冷却 Lv.N = max(0.3, cooldown + cooldown_per_level × (N-1))
数量 Lv.N = count_base + count_per_level × (N-1)
```
