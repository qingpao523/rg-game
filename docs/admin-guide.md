# 管理平台使用说明（小白版）

管理平台用来改游戏数值：技能伤害、波次难度、玩家血量、功能开关等，改完**不用重启服务器**，玩家那边 60 秒内会自动拿到新配置。

## 1. 怎么进入管理平台

1. 打开浏览器，输入地址（二选一）：
   - 本机：`http://localhost:8890/admin/`
   - 远程：把 `localhost` 换成你的服务器地址或域名，后面加 `/admin/`，例如 `http://你的地址:8890/admin/`
2. 输入管理密码（默认：`rg-admin-2026`），点登录。
3. 登录后左侧有导航：仪表盘 / 玩家管理 / 对局记录 / 技能管理 / 游戏配置 / 排行榜 / 公告管理 / 怪物管理。

> 安全提醒：默认密码所有人都知道，如果管理平台要暴露到公网，一定先改密码（通过 `ADMIN_PASS_HASH` 环境变量）。

## 2. 怎么改技能

点左侧「技能管理」，会看到所有技能的表格：图标、ID、名称、流派、行为、标签、等级数。

每个技能右侧有「编辑」和「删除」按钮，右上角有「+ 新建技能」。

### 编辑技能的弹窗字段

| 字段 | 说明 | 小白注意 |
|---|---|---|
| 技能 ID | 技能的唯一英文标识 | 编辑时不能改；新建时才填 |
| 名称 | 游戏里显示的名字 | 可以写中文 |
| 流派 | 如 火焰流 / 雷霆流 | 影响结算的"主导流派" |
| 行为 | 技能在代码里的类型（如 missile、fireball） | **不要乱改**，改成没有的类型技能会失效 |
| 描述 | 游戏里的一句话说明 | 随便写 |
| 标签 | 逗号分隔，如 `防御,被动` | 英文逗号 |
| 投射物 | 弹道图片路径 | 没有弹道的技能留空 |
| 图标路径 / 图标上传 | 技能图标，二选一 | 不传就沿用原图标 |
| 等级数值表 | 每个等级一行 JSON | 见下面单独说明 |

### 等级数值表怎么填

这是最常用的。它是一个 JSON 数组，**一个花括号是一级**，字段名不能改，数值随便改：

```json
[
  { "dmg": 8, "cd": 1.0, "count": 1 },
  { "dmg": 12, "cd": 0.95, "count": 1 }
]
```

上面的意思是：Lv.1 伤害 8、冷却 1 秒、数量 1；Lv.2 伤害 12、冷却 0.95 秒。

不同技能字段不一样（火球有 `radius` 爆炸范围、闪电有 `chains` 弹射次数），**照着原来的字段改数字就行**，不要删字段、不要加没见过的字段。

### 举个实际例子：把魔法飞弹 Lv.1 伤害从 8 改成 20

1. 「技能管理」→ 找到 `magic_missile`（魔法飞弹）→ 点「编辑」；
2. 找到「等级数值表」，把第一行 `{ "dmg": 8, "cd": 1.0, "count": 1 }` 里的 `8` 改成 `20`；
3. 点「保存技能」。

保存后：玩家刷新页面（或等 60 秒），新的一局里魔法飞弹 Lv.1 就是 20 伤害。

### 技能管理的坑

- **删除不可恢复**，删之前想清楚。
- **新增技能**：必须复制一个已有技能的行为（比如都填 `ice_shard`），否则游戏里不会生效。
- 改完数值不用重启服务器，玩家拿到新配置会自动覆盖旧数值。

## 3. 怎么改游戏配置

点左侧「游戏配置」，页面按模块分组：

🧑 玩家基础属性（血量、速度、拾取范围）
📈 局内升级经验曲线（每级要多少经验）
💰 结算奖励（每局结算给多少经验/金币）
💵 局外升级曲线（账号等级经验）
🌊 波次曲线（刷怪速度、难度）
🎁 掉落系统（精英/哥布林掉什么）
🌟 天赋解锁（第几层要投多少点）
🗡️ 武器合成（碎片需求）
⚔️ 技能系统（技能栏数量、进化条件）
🔧 功能开关（转盘、排行榜、跳过升级等开关）

每个输入框下面都标了**路径和允许范围**，例如：

```
waves.baseInterval · 范围 0.1~60
```

意思是"刷怪间隔"这个值只能在 0.1~60 之间填。

### 保存流程

1. 直接改输入框里的数字或勾选开关；
2. 如果填错了（超范围/格式错），输入框会变红，下面的保存按钮会显示"N 个字段待修正"；
3. 改好后点「保存并发布（N 项修改）」；
4. 弹窗显示「✓ 回读一致，配置已发布 vN」就是成功了，版本号每次保存 +1。

### 举个实际例子：让游戏更难一点

1. 「游戏配置」→ 🌊 波次曲线；
2. `waves.baseInterval`（初始刷怪间隔）从 `1.5` 改成 `1.2`（间隔越小怪越多）；
3. `waves.batchBase`（基础批量）从 `2` 改成 `3`（每批怪更多）；
4. 点「保存并发布」。

### 配置的坑

- 填超范围的值会被拒绝，保存按钮也会禁用。
- 有联动关系的字段会自动校验，比如"最小刷怪间隔必须 ≤ 初始刷怪间隔"。
- 每个版本后端会自动存历史（保留最近 30 份），但**管理界面目前没有"回滚"按钮**；要恢复旧值就把数值改回去再保存一次。
- 玩家在战斗中时，新配置会在**下一局**生效，游戏里会提示"配置已更新，下一局生效"。

## 4. 其他页面一句话说明

- **仪表盘**：玩家数、对局数、职业分布等总览。
- **玩家管理**：搜玩家、看存档、封禁/解封。
- **对局记录**：真实对局列表，可按职业、最低波次、最低击杀筛选。
- **排行榜**：查看和重置各职业排行榜。
- **公告管理**：发布游戏内公告（游戏主菜单会展示最新一条）。
- **怪物管理**：改现有怪物的血量/伤害/速度，或新增怪物。

> 怪物管理的坑：目前界面只能填基础属性，**没有"刷怪权重"字段**，所以新增的怪物暂时不会在常规波次里刷出来。想加新怪进波次需要以后给界面补 `spawnWeight` 字段。

---

## 5. 小白通用提醒

1. **改之前先截图或复制原数值**，改坏了能照着改回去。
2. **技能数值表复制一份留底**，JSON 手滑删错字段技能可能失效。
3. 所有改动即时生效，**不需要重启服务器**；玩家刷新页面即可。
4. 删除操作（技能/怪物）不可恢复，谨慎点。
5. 管理密码默认是 `rg-admin-2026`，要暴露到公网前必须换掉。

## 6. AI 配置助手（本地 Ollama）

管理端右下角的 🤖 按钮是一个悬浮 AI 助手，用你本机的 Ollama 模型回答配置问题。

### 它能做什么

- 回答当前游戏数值：血量、技能伤害、波次、怪物属性等；
- 给修改建议：怎么调低前期难度、怎么加强某个流派等；
- 引用具体配置路径和当前值，比如「`player.hp = 120`」。

### 怎么用

1. 点右下角 🤖 打开浮窗；
2. 顶部可以选择模型（默认 `richardyoung/qwythos-9b-abliterated:IQ4_XS`）；
3. 输入问题回车发送，比如：
   - 「当前玩家初始血量是多少？」
   - 「想调低前期难度改哪几个配置？」
   - 「火球术现在伤害多少，怎么加强？」
4. AI 只给建议，**不会直接改配置**；确认后在「游戏配置」/「技能管理」页面手动保存。

### 知识库包含什么

每次提问时自动打包当前状态：

- 游戏配置（config.json 全部字段 + 版本号）
- 全部技能定义（名称、行为、流派、5 级数值）
- 职业、主动技、技能进化、升级属性卡、哥布林奖励
- 武器（合成与效果）
- 怪物定义（内置 4 种 + 服务端自定义）
- 代码知识库：js/、server/、tools/、index.html 共 20 个源码文件建立索引，按问题自动检索相关片段（问「某功能在哪实现」时生效）

配置或技能改完后，知识库**自动跟随最新值**，不用手动刷新。

### 常见问题

- **提示无法连接 Ollama**：确认 Ollama 软件已启动（`ollama serve` / 打开 Ollama App）。
- **回答很慢**：9B 模型在本地生成需要一些时间，首次提问要等模型加载（几十秒到 1-2 分钟），属于正常现象；顶栏可以换更快的模型（如 `qwen3.5:4b`）。
- **为什么先出现灰色斜体的一大段文字**：那是模型的「思考过程」（qwythos 系列支持思考模式），会实时滚动显示；看完后下方才是正式回答，两者都会保留在对话里。
- **可以问代码问题吗**：可以。代码是按问题自动检索的（不是每次全量塞入），例如「武器效果在哪个文件实现」「登录上报的流程在哪」，它会指出相关文件与代码片段；个别文件归属可能不完全精确，以片段实际内容为准。
- **聊太长了会怎样**：对话接近上下文上限（默认 70%）时会自动清理较早的对话，并提示「已自动清理较早内容，本次回答后开始新对话」；本轮回答完会自动开启新对话，不需要手动点清空。
- **想换默认模型**：设置环境变量 `OLLAMA_MODEL=模型名` 后重启服务，或在浮窗顶栏直接选。
