技能管理

📖 使用说明（小白版）
  • 改数值：点「编辑」→ 改「等级数值表」里的数字 → 点「保存技能」。一个花括号是一级，字段名不要删不要改，数值随便填。
  • 例：魔法飞弹 Lv.1 伤害 8 → 20，就把第一行 {"dmg":8} 改成 {"dmg":20}。
  • 「行为」是技能在代码里的类型（missile、fireball…），不要乱改，改成未实现的类型技能会失效。
  • 新增技能：必须复制已有技能的行为（如 ice_shard），否则不会生效。
  • 删除不可恢复；保存后玩家刷新页面（或等 60 秒）即生效，不用重启服务器。
  • 📄 完整版说明：docs/admin-guide.md

游戏配置

📖 使用说明（小白版）
  • 直接改数字或开关，改完点页面底部「保存并发布」；每次保存版本号 +1。
  • 每个输入框下面标了允许范围，超范围会被拒绝并红框提示；有联动关系的字段（如"最小刷怪间隔 ≤ 初始间隔"）也会自动校验。
  • 保存后玩家 60 秒内自动生效；玩家正在战斗时会提示「下一局生效」。
  • 后端每版自动留历史（最近 30 份），但界面暂无回滚按钮，改坏了手动改回去再保存。
  • 📄 完整版说明：docs/admin-guide.md

怪物管理

📖 使用说明（小白版）
  • 改现有怪物的血量 / 伤害 / 速度：点「编辑」→ 改数字 → 保存，玩家 60 秒内生效。
  • 「HP 固定成长/波」= 每波增加多少固定血量；「HP 百分比成长/波」= 每波增加百分之几（0.08 = 8%）。
  • ⚠️ 新增怪物：界面暂无「刷怪权重」字段，新怪暂时不会在常规波次刷出，需要后续补该字段。
  • 删除不可恢复；图片路径要填 assets 里真实存在的图（如 enemies/grunt_move.png）。
  • 📄 完整版说明：docs/admin-guide.md
